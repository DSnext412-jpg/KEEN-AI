## 🚀 About

**KEEN AI** is a smart AI-powered productivity assistant designed to simplify everyday work.

Whether you need to chat with AI, summarize documents, manage notes, automate tasks, or organize your workflow, KEEN AI brings everything together in one modern workspace.

---

## ✨ Features

- 🤖 AI Chat Assistant
- 📄 PDF Summarizer
- 📝 Smart Notes
- 📂 File Search
- 🎤 Voice Commands
- 📋 Clipboard History
- 🌦 Weather Updates
- 🧮 Calculator
- 📅 Reminders & Calendar
- ⚙️ Task Automation
